# 생활안전지도와 안전시설 데이터를 활용한 우회경로 알고리즘 보고서

- 프로젝트: Safe Return Home
- 작성일: 2026년 10월 11일
- 기준: 현재 프로젝트에 구현된 코드와 이번 세션의 검증 결과
- 범위: 안심 우회경로 후보 생성, 실제 보행경로 확인, 경로 평가 및 선택

## 1. 구현 목적

본 프로젝트의 안심 우회경로 기능은 일반 보행경로와 대안 경로를 비교하여, 범죄주의등급이 높은 구간의 통과를 줄이고 CCTV·가로등과 가까운 구간을 이용하도록 경로를 추천하는 기능이다. 추가 이동거리에 제한을 두어 과도한 우회를 방지한다.

사용하는 범죄주의등급과 시설 근접도는 경로 비교를 위한 지표이다. 실제 범죄 발생 확률, CCTV 촬영 범위 또는 조도를 측정한 값은 아니다.

## 2. 사용 데이터 및 API

| 데이터·서비스 | 사용 목적 | 현재 적용 내용 |
|---|---|---|
| TMap 보행자 경로 API | 일반경로 및 경유지 포함 경로 생성 | 실제 도로 경로선과 거리 확보 |
| 생활안전지도 범죄주의구간(전체) WMS | 범죄주의등급 기반 후보 생성과 최종 평가 | `IF_0087_WMS`, 레이어 `A2SM_CRMNLHSPOT_TOT`, 스타일 `A2SM_CrmnlHspot_Tot_Tot` |
| 생활안전지도 범례 API | 지도 색상을 등급으로 해석 | `lgdInfo`, `intId=IF_0087`, 1~10등급 |
| CCTV 공공데이터 | 시설 기반 경유지 생성과 실제 경로의 근접도 평가 | 좌표, 설치 대수, 경로 후보 적합 여부 활용 |
| 가로등 공공데이터 | 후보 및 실제 경로의 시설 점수 보완 | 좌표와 설치 대수 활용 |

생활안전지도 호출 주소는 `https://www.safemap.go.kr/openapi2/IF_0087_WMS`이다. 현재 여성밤길안전, 시간대별 범죄 또는 개별 범죄 유형별 레이어를 나누어 사용하지 않는다. WFS는 현재 경로 계산에 적용되어 있지 않다.

## 3. 알고리즘 처리 과정

### 3.1 일반경로 확보

출발지와 목적지를 기준으로 TMap 일반 보행경로를 요청한다. 일반경로의 경로선과 거리는 후보 생성 범위와 우회거리 제한의 기준으로 사용한다. 일반경로를 확보한 뒤에는 이후 후보 요청이 지연되어도 해당 결과를 유지한다.

### 3.2 CCTV·가로등 기반 후보 생성

출발지와 목적지 주변에서 경유 후보로 사용할 CCTV 좌표를 선별하고, 최대 72개 노드의 경유지 그래프를 구성한다. 각 연결 구간의 거리와 시설 근접도를 비용으로 평가하여 A* 탐색으로 경유지를 최대 3개 선정한다.

선정한 경유지로 TMap 보행경로를 요청한다. 시설 기반 후보는 최대 4회 시도하여 유효한 경로를 최대 2개 확보한다. 서로 다른 경유지가 동일한 실제 도로 경로를 만들면 중복 후보로 처리한다.

### 3.3 생활안전지도 기반 후보 생성

일반경로 주변까지 포함하는 WMS 이미지를 조회한다. 후보 탐색 범위는 일반경로 길이의 18%를 기준으로 하되, 경로에서 150~450m 이내로 제한한다.

이미지를 약 100m 단위 셀로 나누고, 각 셀에서 범죄주의등급을 확인할 수 있는 도로 픽셀을 추출한다. 투명하거나 등급을 판독할 수 없는 픽셀은 경유지로 사용하지 않는다. 추출한 점 중 일반경로의 평균적인 등급 가중값보다 낮고 탐색 범위 및 예상 우회거리 조건을 만족하는 점을 후보 노드로 선정한다.

후보 노드를 경로 진행 순서로 연결하고, 경유지 수를 상태로 둔 동적 계획법으로 거리와 등급 노출 비용이 낮은 조합을 찾는다. 경유지는 최대 3개이며, 첫 조합에서 사용한 노드를 제외하여 두 번째 조합을 탐색한다. 이 과정에서 최대 2개의 생활안전지도 기반 후보를 생성한다.

이 단계의 연결 비용은 직선 구간의 추정치이다. 구간을 약 40m 간격으로 평가하여 다음 비용을 적용한다.

```text
연결 비용 = 구간 거리 + 4 × 등급 노출 점수
경유지 추가 비용 = 경유지당 15
```

CCTV 경유지가 없는 경우에도 생활안전지도 기반 후보를 생성할 수 있다. 다만 기준 경로의 등급 확인 비율이 65% 미만이거나 경로·출발지와 목적지 사이의 거리가 너무 짧으면 후보를 생성하지 않는다.

### 3.4 실제 보행경로 확인

생활안전지도에서 선정한 경유지 역시 TMap에 전달하여 실제 보행경로를 확인한다. WMS에 색칠된 픽셀이 존재한다는 사실만으로 도로 연결성을 판단하지 않는다.

후보 경로에 대해서는 다음 조건을 검사한다.

1. 실제 보행경로 조회가 성공하고 경로선이 존재하는가.
2. 일반경로 대비 추가 거리가 허용 범위 안에 있는가.
3. 되돌아가는 반복구간이 과도하지 않은가.
4. 이미 확보한 실제 도로 경로와 중복되지 않는가.

최종 비교 대상은 시설 기반 후보 최대 2개, 생활안전지도 기반 후보 최대 2개, 일반경로 1개로 최대 5개이다. 조회 실패나 조건 미충족에 따라 실제 비교 대상 수는 줄어든다.

## 4. 경로 평가 및 선택 기준

### 4.1 범죄주의등급 노출 점수

TMap이 반환한 실제 경로를 약 10m 간격으로 확인하여, 등급과 해당 등급을 통과하는 거리를 누적한다.

```text
등급 노출 점수 = Σ[구간 거리 × (범죄주의등급 / 10)²]
                + 등급을 확인하지 못한 구간의 거리
```

높은 등급의 구간을 오래 통과할수록 점수가 커진다. 등급이 없는 구간에도 비용을 부여하여, 데이터 누락이 경로를 더 안전하게 보이게 하는 것을 방지한다. 7등급 이상 구간의 통과 거리도 별도로 계산하지만, 해당 구간을 일괄적으로 통행 금지하지는 않는다.

### 4.2 시설 근접도

실제 경로 주변 180m 이내의 CCTV와 가로등 수를 사용해 시설 근접도를 평가한다. 시설 기반 비용은 거리와 시설 근접도를 함께 고려하며, 가로등 근접도는 보조 가중치 0.35로 반영한다.

180m는 알고리즘의 평가 반경이다. 실제 CCTV 촬영거리나 가로등의 조명 도달 범위를 뜻하지 않는다.

### 4.3 우회거리 제한

```text
허용 경로 거리 = 일반경로 거리
                + max(100m, 일반경로 거리의 30%)
```

예를 들어 일반경로가 1,000m이면 1,300m까지 허용한다. 일반경로가 200m이면 300m까지 허용한다.

### 4.4 최종 선택

등급 정보의 확인 비율이 65% 이상이고, 첫 번째 기준 후보보다 확인 비율이 최대 5%p 낮은 범위 안에 있는 경로끼리 비교한다. 비교 대상 중 최소 등급 노출 점수에서 25 이내인 후보들을 추린 다음 시설 기반 비용이 낮은 경로를 선택한다. 시설 비용도 같으면 거리가 짧은 경로를 선택한다.

첫 번째 기준 후보의 등급 정보가 부족하거나 비교 가능한 경로가 충분하지 않으면 기존 우선 후보를 유지한다. 생활안전지도 조회가 실패하면 생활안전지도 기반 후보를 생성하지 않고 기존 후보로 선택한다. CCTV 조회가 실패해도 생활안전지도와 가로등을 이용한 탐색은 계속하도록 구현되어 있다.

## 5. 별도 위험구역 회피 기능

지정된 원형 위험구역을 피하는 우회 기능은 위 안심경로 추천과 별도의 방식으로 구현되어 있다. 위험구역 주변 8방향과 4개 거리 조합으로 최대 32개의 경유 후보를 생성한다. 각 후보를 TMap 실제 경로로 변환하고, 위험구역 반경에 10m 완충 범위를 더한 영역을 통과하는 경로를 제외한다.

남은 후보 중 현재 경로 대비 추가 거리가 적은 경로를 선택하며, 추가 거리가 같으면 예상 도보 시간과 후보 순서를 사용한다. 이 기능은 지정된 위험구역의 회피 여부를 기준으로 동작한다.

## 6. 구현 및 검증 현황

현재 시설 기반 후보 생성, 생활안전지도 기반 후보 생성, TMap 실제 경로 확인, 우회거리·반복구간 제한, 최종 경로 비교가 연결되어 있다. 경로 미리보기와 안내 시작 과정에 같은 후보 탐색 절차를 사용한다.

이번 세션에서 앱 및 테스트 코드 컴파일이 성공했고, 관련 단위 테스트 37개가 통과했다. 단위 테스트는 Gradle 테스트 프로세스의 시작 오류로 JUnit을 직접 실행하여 확인했다.

검증에는 낮은 등급의 도로를 이용한 후보 생성, 투명한 지도에서의 후보 생성 방지, 등급 정보가 부족한 경로의 처리, 불필요한 우회 방지, 경유지 수 제한, 실제 경로선의 등급 노출 계산 및 우회거리 제한 등이 포함된다. 실제 기기에서 TMap 경로가 어떻게 변환되는지와 현장 경로 품질은 아직 확인하지 않았다.

## 7. 현재 한계와 개선 과제

현재 방식은 제한된 후보를 생성하여 평가하는 추천 알고리즘이다. 전체 도로망의 모든 대안을 탐색하지 않으므로 전역 최적 경로나 가장 안전한 경로를 보장하지 않는다. 두 경유지 조합이 실제로는 같은 도로로 변환되어 후보 수가 줄어들 수도 있다.

WMS 이미지의 해상도와 지도 좌표 차이로 등급 판독에 오차가 발생할 수 있다. 시설 평가에는 건물·벽·카메라 방향·가로등 밝기와 작동 상태가 반영되지 않는다. 또한 현재 사용하는 전체 범죄주의등급에는 경로 구간별 시간대 정보가 없으므로, 시간대별 범죄 다발 장소를 식별하지 못한다.

후속 개선 과제는 여러 출발지·목적지에서 일반경로와 추천경로의 추가 거리, 등급 노출 점수 및 데이터 확인 비율을 비교하는 현장 검증이다. 장소와 시간대가 연결된 데이터를 확보하면 구간별 예상 통과 시간까지 고려하는 평가로 확장할 수 있다.
